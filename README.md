# Keuzedeel: Oriëntatie op applicatieontwikkeling

Deze repository bevat een eenvoudige GitHub Pages-site voor het keuzedeel "Oriëntatie op applicatieontwikkeling".

## Inhoud

- `index.html` — hoofdpagina
- `styles.css` — styling
- `script.js` — kleine JavaScript-actie

## GitHub Pages

Na het activeren van GitHub Pages in de repository-instellingen, wordt de site beschikbaar via:

https://tiemenbouma.github.io/keuzedeel-orientatie-op-applicatieontwikkeling/

## Opmerking

Deze site is opgebouwd als een statische pagina, zodat hij eenvoudig gepubliceerd kan worden met GitHub Pages.
